# Content usage analysis

For this assignment, I analyzed JetBrains article about discontinuation of JetBrains IDE Fleet: https://blog.jetbrains.com/fleet/2025/12/the-future-of-fleet/

Spreadsheet with my findings: https://docs.google.com/spreadsheets/d/1js68QZD8jFLb2auvIfnbzE5MzGzg_Uq9FSSA966AQgY/edit?usp=sharing

This article announces that support of Fleet will be discontinued and it will be no longer available for download from December 22, 2025. It was developed as an experiment in building a new generation of JetBrains IDEs, but maintaining two general-purpose IDE families created confusion and diluted focus. JetBrains is redirecting the Fleet team and technology toward a new product focused on agentic development.

I chose specifically this article, since Fleet started as a very ambitious project that was much discussed among developers, and the discontinuation new of Fleet was one of the most important new made by JetBrains in recent months. This article should be referenced, discussed and reused outside its original context.

## Methodology

I treated this task as a content-tracing exercise. The goal was not to find every possible mention, but to build a reproducible way to identify how the article was referenced, discussed or reused outside its original context.

I used several types of search queries:

* original article URL 
* exact article title (didn't use for automated search, only manual search)
* alternative versions of the title (didn't use for automated search, only manual search)
* short generated summaries of the article
* key phrases from the article (didn't use for automated search, only manual search)

The search process was partially automated. Using Miyami websearch tool, integrated in my tool, I fetched content of article using URL with article. Then I integrated Hugging Face model BART by Facebook to get short summary of article. Since HF model generates different summaries each time, for better accuracy I generated different summaries using this model.

After getting different summaries, generated by HF model, I used them (as well as URL of initial article) for getting references. For automated search, I used again Miyami websearch tool to get search results for each search query.

After that I tried using another HF model by Facebook for classification (which can be seen at the code), but results of classification were too unstable for using them in spreadsheet. That's why I used URLs that I got at previous stage and manually checked links and reference to the original article.

For manual search I used article title and some more clickbait versions of the title (like "JetBrains discontinued the IDE" or "JetBrains shuts down Fleet for AI"). I didn't use titles for searching using Miyami websearch tool, since I got too many unrelated results.

I used multi-label classification approach because one source usually use article in more than one way, for example, Reddit post can directly link to the original article and contain discussion in comments.
